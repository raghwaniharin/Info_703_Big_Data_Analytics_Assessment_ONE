Assessment 1: Descriptive Analysis of Hotel Booking Dataset
📄 Overview

This project is part of my INFO703 Big Data and Analytics course at WINTEC. Assessment 1 involves performing descriptive analysis on a hotel booking dataset. The goal is to extract meaningful insights from a large dataset using data cleaning, exploration, and visualization techniques.

🏨 Dataset
Source: Kaggle – Classify Hotel Reservations
Records: ~36,000
Attributes: Includes booking dates, length of stay, number of guests, booking status, lead time, and more.

📊 Objectives
Understand patterns in hotel bookings.
Identify trends such as booking cancellations, average stay durations, and seasonal variations.
Generate summary statistics and visualizations to support insights.

📈 Key Findings
Higher cancellation rates are associated with longer lead times.
Most bookings are made for 1-2 nights.
Peak booking months occur during summer.
Corporate clients tend to cancel less often than others
